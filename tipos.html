Tipos de IA

No toda la IA funciona igual. Cada tipo se usa para resolver problemas diferentes.

IA débil

Hace una tarea específica, como desbloquear un celular, recomendar videos o responder preguntas.

Machine Learning

Aprendizaje automático: el sistema aprende usando datos sin programar cada decisión manualmente.

IA generativa

Crea contenido nuevo como textos, imágenes, música, diseños, código y presentaciones.

Robótica inteligente

Une sensores, programación e IA para que una máquina pueda actuar en el mundo físico.
